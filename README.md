# cs50p — My journey through CS50's Introduction to Programming with Python

This repo contains my self-taught exercises following Harvard's **CS50P** course
(https://cs50.harvard.edu/python/), freely available on YouTube and edX.

> Note: this is **not** an official submission via `submit50`. It's a personal
> open-source repo to track my progress and understand the code's logic.

## Final Project — Inflation Impact Analyzer

A price-tracking pipeline that scrapes a product's price, logs the history
to CSV, plots a price trend graph, and compares the observed change to the
official inflation rate, automated to run weekly via GitHub Actions.
